Introduction to Airflow

Apache Airflow is a data orchestration tool, well, its just a fancy way to organize your python scripts and run them one after the other

Airflow consists of following main components -

  1. Web-server
  2. Worker
  3. Scheduler
  4. Database - Airflow uses a database to store all the data regarding

In most production setups, Airflow is running in a distributed fashion i.e you have a web-server that serves the UI and workers where the actual data gets processed. The workers and web-server communicate via REST APIs. Airflow also uses a database to store all the details about dags, jobs, runs etc.

Airflow has hundreds of configuration to setup when you get started, but there are few that you absolutely need to change/tune when you are setting up it production. It can be quite overwhelming looking at the airflow.cfg file as it is very long (2000 lines long, well, that includes their extensive documentation for every config)
